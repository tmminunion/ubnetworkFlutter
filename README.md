# UBnetwork

Aplikasi Android **Native Flutter** berbasis offline-first untuk **Record Daily Control**, kanvas lembar kerja digital interaktif, dan pengelolaan aktivitas harian terpadu.

## Fitur Utama
- **Record Daily Control (Kanvas Lembar Kerja Interaktif):** Pinch-to-zoom 2 jari, geser bebas (pan), kontrol zoom presisi (`- | % | +`), Fit-Width (`⛶`), dan tampilan kertas digital responsif.
- **Pencatatan Harian Terstruktur:** Input langsung di atas kanvas untuk rencana kerja, capaian aktual, rekap kehadiran tim, evaluasi kendala, serta catatan tindak lanjut harian.
- **Hub Aktivitas & Kolaborasi:** Dilengkapi papan tugas harian, pencatatan ide perbaikan berkelanjutan, jadwal berkala, serta pengelolaan dokumen kerja.
- **Offline-First + Cloud Sync:** Data tersimpan otomatis di penyimpanan lokal perangkat dan mendukung sinkronisasi online secara aman.
- **Cetak / Ekspor PDF:** Ekspor lembar kerja langsung ke dokumen PDF resolusi tinggi siap cetak.
